How do I send something for the first time?

Open XCopy on both computers. Enter the other device's 8-digit pairing code and confirm there. Select the online device, paste text or a screenshot, or attach files, then send. Keep both pages open.

Can Windows, Mac and Linux exchange files?

Windows and Mac users can open XCopy in Chrome or Edge. Linux servers and Raspberry Pi can use the xcopy command-line client to exchange text and files with browsers and save received content to a directory. Both sides must be online.

How fast are transfers?

XCopy prefers direct P2P transfers without uploading to a cloud drive first. Speed depends on both networks, connection type and file size. Relay is used when a direct connection cannot be established.

Can I send to several devices at once?

Yes. Select all online devices to broadcast, or select a single device. Broadcast sends only to directly paired devices that are online when you press send.

Does changing the pairing code affect existing connections?

No. Codes create new pairings. Updating or expiring a code does not remove existing pairings. Pairings remain until explicitly forgotten. Finish all transfers before forgetting a device.

Do I need to pair again after reopening my browser?

Usually not, if you use the same browser profile and URL and retain site data. A different browser or profile, or clearing site data, requires pairing again.

Where is content stored?

Text, screenshots and files travel directly between devices using P2P when possible. If a direct connection fails, a relay forwards the encrypted traffic without storing file content.

Received content stays in the current recipient page. Save files and copy any text you need before refreshing or closing it.

The server stores device information and pairings so devices can reconnect. It does not store transfer content.

Can I transfer across different Wi-Fi networks?

Yes, when the deployment provides the necessary connectivity. XCopy attempts P2P first and uses the configured relay when needed. Both devices need internet access and must keep their transfer pages open.

Is there a file size limit?

Up to 10 files at a time. Direct P2P has no file size limit; the service administrator sets the relay limit. Keep both pages open.
