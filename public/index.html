第一次使用，怎么传？

两台电脑打开随传的传输页，输入对方的 8 位连接码，对方确认后即可完成配对。选择在线设备，粘贴文字、截图或添加文件，点击发送即可。双方需保持传输页打开。

支持 Windows、Mac 和 Linux 之间互传吗？

Windows 和 Mac 电脑可使用 Chrome 或 Edge 打开网页版，配对后互传文件、文字和截图。Linux 服务器和树莓派可安装 xcopy 命令行客户端，与浏览器双向传输文件和文字；接收内容保存到指定目录。双方均需在线。

传输速度有多快？

随传优先在两台设备之间通过 P2P 直传，无需先上传到云盘，再让对方下载。实际速度取决于双方网络、连接方式和文件大小；无法直连时会通过服务器中转。

能一次发给多台设备吗？

可以。选择「全部在线设备」即可群发，也可以选择一台设备单发。群发只发送给点击发送时，与本机直接配对且在线的设备。

连接码更新，还能继续传吗？

可以。连接码只用于发起新配对，更新或过期不会解除已有配对。配对关系长期保留，只有手动忘记才会解除。忘记设备前，双方的传输任务需先结束。

重新打开浏览器，需要重新配对吗？

同一浏览器配置、同一网址且站点数据保留时，一般不需要。换浏览器、换配置或清除站点数据后，需要重新配对。

内容会保存在哪里？

文字、截图和文件优先通过 P2P 在两台设备之间点对点直传。无法直连时（例如打洞失败），才通过服务器中转；中转服务器只负责转发，不保存或留存任何文件内容。

收到的内容暂存在接收端当前页面中。刷新或关闭页面前，请保存需要的文件、复制需要的文字。

为记住已配对设备，服务端会保存设备信息和配对关系，但不保存传输内容。

不在同一个 Wi-Fi 下，也能传吗？

可以。随传优先尝试 P2P 点对点直传，打洞失败、无法直连时使用服务器中转，中转不留存文件。双方需要联网，并保持随传的传输页打开。

文件大小有限制吗？

一次最多 8 个文件。P2P 直连不限文件大小；中转上限由服务管理员配置。请保持双方页面打开。
