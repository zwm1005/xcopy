XCOPY CLI · v0.1.2

没有桌面，也能随手传。

让 Linux 服务器、Debian 和树莓派与浏览器互传文字、文件。配对一次，后台常驻，收到的内容直接保存到你的目录。

Linux amd64 ↓Intel / AMD · x86_64 Linux arm64 ↓树莓派 64 位系统 · aarch64

运行 uname -m 查看架构。暂不支持 32 位 ARM 系统。 SHA-256 校验文件 · 完整中文说明

1. 安装客户端

以下以树莓派 arm64 为例；x86_64 主机把命令中的 arm64 换为 amd64。

curl -fLO https://xcopy.werfamily.fun/downloads/xcopy/v0.1.2/xcopy_0.1.2_linux_arm64.tar.gz
curl -fLO https://xcopy.werfamily.fun/downloads/xcopy/v0.1.2/SHA256SUMS
sha256sum --ignore-missing -c SHA256SUMS
tar -xzf xcopy_0.1.2_linux_arm64.tar.gz
cd xcopy_0.1.2_linux_arm64
sh install.sh
export PATH="$HOME/.local/bin:$PATH"

2. 配置后台与接收目录

xcopy init --name raspberry-pi --receive-dir "$HOME/xcopy/inbox"
xcopy service install --user --start
sudo loginctl enable-linger "$USER"
xcopy status

普通用户运行安装和初始化。enable-linger 用于退出 SSH 后保持在线及开机启动。没有 systemd 时可直接运行 xcopy serve。

3. 和浏览器连接

打开浏览器传输页，点击「连接设备」，将页面上的 8 位连接码输入终端，再回到浏览器确认。

xcopy pair join 12345678
xcopy devices

4. 双向传输

xcopy send ./app.log --to 我的电脑
printf '树莓派运行正常\n' | xcopy send --stdin --to 我的电脑
xcopy inbox
xcopy transfers --follow
xcopy read 记录ID

浏览器选择你的 Linux 设备即可发回文件。发送命令默认等待接收方确认；同名文件会另取名称，收到的内容不会自动执行。

文件上限 50 MiB，文字上限 1 MiB。双方需在线并已配对。支持加密直传及 TURN 中继；中断后请重新发送，当前版本不支持离线投递和断点续传。
