XCopy command-line client

简体中文

Use XCopy on Linux servers and Raspberry Pi to send files and text to paired browsers. Obtain the package and SHA256SUMS from your service administrator, verify the checksum, then extract the archive and place the executable on your PATH. Select the package matching your operating system and architecture.

Use your own server

xcopy init --server https://send.example.com
xcopy serve

Replace the example origin with your administrator's HTTPS URL. The older CLI default server remains for compatibility; always specify --server for self-hosting. Run xcopy --help for pairing and send/receive commands. Keep the daemon online while transferring and configure its receive directory before sending files to it.

The CLI and browser obtain STUN/TURN configuration from the same application server. Do not copy the server's TURN shared secret into a client. Received files are saved locally; pairing and device credentials belong to your local CLI profile.
